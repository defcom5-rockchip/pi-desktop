Download and install

Two images (Plaid Pi is the new name of Pi-Desktop). Plaid Pi Plus 6.5 for the Orange Pi 5 Plus: Plaid-Pi-Plus-6.5-orangepi5-plus.img.zst, KDE Plasma. Plaid Pi 6.0 for the Orange Pi 5B and the Orange Pi 5: Plaid-Pi-6.0-orangepi5b.img.zst, GNOME. Each with one checksum file next to it. Pick the one for your board; the rest of this page applies to both.

Plaid Pi Plus 6.5 (Orange Pi 5 Plus) on GitHub Plaid Pi 6.0 (Orange Pi 5B and 5) on GitHub

What you need

  • An Orange Pi 5 Plus (the 6.5 image), an Orange Pi 5B or the original Orange Pi 5 (both use the 6.0 image). The 5 Plus and the 5B are the boards the images are built for and tested on; the 5 is supported through issues and the recipe (HW-1); what was not tested on the 5 Plus is in HW-2.
  • A microSD card of 16 GB or more (the 6.5 image is about 7.14 GiB uncompressed, the 6.0 image 6.50 GiB; both grow to fill the card on first boot), or the 5B's eMMC.
  • An HDMI monitor, keyboard and mouse for the first boot. 120 Hz needs an HDMI 2.1 monitor and cable; 4K at 60 Hz works on any 4K HDMI monitor.
  • A power supply rated for the board. A marginal phone charger browns out under load and looks exactly like a software crash.

1. Verify the checksum

Each release ships the image and a .sha256 file next to it. On Linux or macOS, in the folder you downloaded to:

sha256sum -c Plaid-Pi-Plus-6.5-orangepi5-plus.img.zst.sha256
# expected output: Plaid-Pi-Plus-6.5-orangepi5-plus.img.zst: OK
# (6.0: the same with Plaid-Pi-6.0-orangepi5b.img.zst.sha256)

On Windows: certutil -hashfile Plaid-Pi-Plus-6.5-orangepi5-plus.img.zst SHA256 and compare with the contents of the .sha256 file. The 6.5 image's checksum is 2b73c85faa0cc0dc63372f404eda59ab2378347b04377b30f575664a501bd61f; the 6.0 image's is a851c7108c0618765c791a7b1ec0690178bbaf13f49c7fbea95692fd25ed3f16.

2. Write the image

Writing the image erases the card or eMMC completely. Pick one method.

GNOME Disks (Linux)

  1. Insert the card. Open Disks, select the card in the left column — check its size, not just its name.
  2. Menu (⋮) ▸ Restore Disk Image…, choose the downloaded image. Disks reads .xz images directly; for a .zst image decompress it first (zstd -d).
  3. Start Restoring, wait for it to finish, then eject.

balenaEtcher (Linux, macOS, Windows)

  1. Flash from file ▸ select the downloaded image (if Etcher refuses the compressed file, decompress it first).
  2. Select target ▸ the card. Check the size.
  3. Flash. Etcher verifies the write itself.

dd (Linux, macOS)

Find the device first (lsblk on Linux, diskutil list on macOS) and make sure it is the card, not your system disk. Replace /dev/sdX:

zstd -dc Plaid-Pi-Plus-6.5-orangepi5-plus.img.zst | sudo dd of=/dev/sdX bs=4M status=progress conv=fsync
sync

3. First boot

  1. Insert the card, connect the monitor, keyboard and mouse, power on. The first boot takes longer: it grows the filesystem to the whole card.
  2. Armbian's setup runs in a text console: it first asks for a root password, then a user name, a password, your real name and a shell. Plaid Pi then asks for a computer name (it suggests <user>-plaidpi). The time zone and locale are suggested from your public IP address (see the privacy page) and can be changed.
  3. After the setup you get the login screen, at this and every later boot (on 4.0 the setup session logged you in once without asking).
  4. On an HDMI 2.1 monitor, 120 Hz is in Settings ▸ Displays ▸ Refresh Rate (6.5, KDE: System Settings ▸ Display & Monitor). Plaid Pi How-To.txt on the desktop explains screen scaling at 120 Hz, how to get Google Chrome, and the apps that install on first click.
  5. Firefox, LibreOffice, GIMP, Inkscape, Thunderbird, VSCodium and Google Chrome are in the app grid (6.0) or the Application Launcher (6.5, where Chromium is one more) as placeholders; the first click downloads the real app from its own repository (you will be asked for your password).
Wi-Fi during setup: the wizard can join a Wi-Fi network for the time-zone lookup. WPA3 and WPA2/WPA3 networks work on both images (the 5B's AP6275P needed kernel patch 0006, which Armbian merged on 2026-10-21; the 5 Plus test board uses an Intel AX210).

4. Installing to eMMC

Orange Pi 5B only, for now: the guide and the helper were written for the 5B's onboard eMMC and have not been run on a 5 Plus (its eMMC socket was empty on the test board).

The 5B's onboard eMMC is faster and more reliable than any microSD, and it is also where most "I installed it and the board misbehaves" reports come from: on RK3588 the bootloader and the operating system can come from different places, and copying a root filesystem onto the eMMC does not install a bootloader. Write the whole image to the eMMC, from a running Plaid Pi on a microSD, and read EMMC-INSTALL.md first — it covers identifying the right device, wiping a factory-Android eMMC, and maskrom recovery.

Something wrong?

Read KNOWN-ISSUES first. Then open an issue with your board revision, how you installed (SD / eMMC), your monitor's resolution and refresh rate, and uname -a. Security problems go through the security page.
