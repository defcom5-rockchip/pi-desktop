Plaid Pi — the new name of Pi-Desktop — gives you 4K at 120 Hz over HDMI out of the box, a flicker-free desktop, hardware video including AV1, Wi-Fi that joins your network, Bluetooth that survives Wi-Fi — and a known-issues file on purpose.

What it is

A GNOME 50 desktop image for the Orange Pi 5B (RK3588S), built from Ubuntu 26.04 packages with the Armbian build framework, on Armbian's Rockchip vendor kernel merged with upstream stable Linux 6.1.189 plus the Plaid Pi kernel patches. Not affiliated with or endorsed by Canonical or Armbian. Not a Raspberry Pi product.

Everything below was checked on an Orange Pi 5B running the 5.0 release image (2026-10-19: 133 of 133 first-boot checks passed, and again after all seven first-click apps and Pro Updates had run), unless an item says it was measured on 4.0.

  • 4K at 120 Hz over HDMI. The vendor kernel reaches HDMI 2.1 FRL with our clock patches; the three ways it failed on the way there (black screens, a hang on screen-off, a black screen after a monitor power-cycle) are fixed by kernel patches, each re-tested on hardware.
  • Flicker-free. Arm's Mali user-space driver instead of Mesa panfork, and AFBC scanout rejected in the kernel. The Chromium typing and thumbnail flicker of 2.0.x is gone.
  • Hardware video, 10-bit and AV1 included, in the browser that ships with it. Our rockchip-vaapi driver 3.5.0 on our build of Rockchip's MPP library. Measured on 4.0 (2026-10-03): Chromium decodes a 4K HEVC Main 10 file on the video engine — 595 frames, none dropped, about a fifth of the CPU — so Jellyfin direct-plays 10-bit with no server transcode, out of the box; Chromium is 155 in 5.0. VP9 now runs on both decoder cores (25–29 % more throughput; the fix is submitted upstream as rockchip-linux/mpp#976). AV1 is new in 5.0: Firefox, installed on first click with our small Mali library, plays YouTube 4K60 AV1 on the video engine with 1.2–1.5 % of frames dropped after start-up, where driver 3.0.0 dropped 91–95 %; Chromium and Chrome start AV1 playback clean in 10 of 10 measured first plays. mpv goes through VA-API, with profiles for DVDs and Blu-rays.
  • Wi-Fi joins WPA3 and WPA2/WPA3 networks. A one-branch bug in the vendor Wi-Fi driver refused every modern home network with Ubuntu 26.04's wpa_supplicant; fixed, and sent upstream (armbian/linux-rockchip#561).
  • Bluetooth that survives Wi-Fi. The AP6275P boot-race and coexistence fixes from 2.0.x, carried over with the self-healing sentinel. The ten-second mute at every YouTube ad on a Bluetooth speaker is gone.
  • Audio. PipeWire 1.6.9 with real-time priority from boot; the 3.5 mm jack works and follows plugging; Rhythmbox 3.5.1, Audacity, Brasero.
  • Screensaver instead of blanking, lock on demand, a login screen at every boot with the Plaid Pi logo on it.
  • Fixes you would otherwise find yourself. GUI password prompts that hang on Ubuntu 26.04 with a 6.1 kernel; a large file copy that could get the whole session killed; every board called "pidesktop".
  • Small image, apps on first click. 1.38 GiB compressed. Firefox, LibreOffice, GIMP, Inkscape, Thunderbird, VSCodium and Google Chrome download from their own repositories on the first click; all seven ran on the 5.0 image on hardware.
  • Updates by themselves. Ubuntu's security updates and the browsers' own repositories update daily; Pro Updates 1.5.0 shows and applies the rest when you open it. The kernel and boot packages are held and change only with Plaid Pi releases.
  • No snaps. No telemetry of our own. What the base still talks to is on the privacy page. Armbian's browser policies (start page, bookmarks) are not applied in 5.0.

Honest scope

One maintainer, a vendor 6.1 kernel, best effort. It ships a KNOWN-ISSUES file on purpose — we'd rather tell you what's rough than let you find out. Suspend is disabled. 10-bit video is hardware-decoded in Chromium, Chrome and mpv, and in Firefox through our launcher library; AV1 in Chromium can show a rare stale frame mid-stream. On long 10-bit VP9 transcodes, the video library most RK3588 images ship drops about 30 % of the frames — measured here, root cause found and the fix sent upstream; Plaid Pi is not affected. HDR on the maintainer's monitor stays pale, and that is the monitor. The board has two display outputs, HDMI 2.1 and DisplayPort over USB-C, nothing else; a passive HDMI-to-DisplayPort adapter cannot work on any computer.

Security updates for the Ubuntu packages come from Ubuntu's repositories for the life of 26.04. The kernel and boot packages are built from Armbian's branch, merged with upstream stable by Plaid Pi, and refreshed with Plaid Pi releases: a new kernel means installing the new image. Plaid Pi's own packages are updated with releases. There is no guaranteed support period and no commercial product behind this. The security page says how to report a problem.

The recipe is public

Built on Armbian, by hook. Plaid Pi images are built from pinned Armbian build-framework inputs. Armbian owns the RK3588 boot chain: U-Boot, partition layout, kernel branch, device trees, modules, firmware, board-support packages and the first-boot filesystem resize. Plaid Pi changes the kernel there: upstream stable 6.1.189 merged into Armbian's branch, and its own patches (0001–0017) applied through Armbian's own userpatches mechanism, all published with the source. Everything else is a userspace layer applied through Armbian's late image hook, customize-image.sh, and every line of it is in the recipe repository. The images are credential-free: there is no default user or password, the first boot creates yours.

Don't trust the image; audit the recipe.
